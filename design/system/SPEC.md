# Kindle Home — 実装仕様書

対象: Kindle Paperwhite 4（1072 × 1448 px、300 dpi、16 階調グレースケール）
デザイン正本: `design/system/src/*.html` / `design/system/screens/*.png`
この仕様書の座標はすべて HTML の絶対配置 px と一致している。

---

## 0. 座標系と前提

- 原点は画面左上。x は右、y は下。単位は 1 px（300 dpi のデバイスピクセル）。
- 画面サイズは **1072 × 1448**。回転・拡大縮小はしない。
- すべての矩形・線・文字は整数 px。8 px グリッドを基本単位とする。
- 文字は **ベースライン基準**で描く（§1.4）。HTML の `top` は CSS の行ボックスの
  上端であり、ベースラインは `top + オフセット` で求まる。C 実装では各表の
  「baseline」列の y に文字のベースラインを置く。テキスト行の高さ h は
  font-size（line-height: 1）に等しいため、表では baseline を正として h を省略する。
  幅が `auto` の行は同じフォント・サイズ・字間で実測する。
- 色は 4 値のみ（§1.1）。影・ぼかし・グラデーション・半透明は使わない。
- 罫線は 3 px 以上。1 px 線は存在しない。

### 1.4 ベースラインの求め方

- フォントは `line-height: 1` で配置する。
- `SerifB` / `SerifR`: ベースライン = top + round(0.9325 × size)
- `SansM`: ベースライン = top + round(0.936 × size)
- 表の baseline は 8 px グリッドに丸めた設計値。±1 px の差は許容する。

### 1.5 線幅

| 用途 | 幅 |
|---|---|
| 罫線（横） | 3 px |
| お気に入りのイニシャル枠 | 5 px |
| アプリの円枠 | 4 px |
| 戻る矢印・＋／－・シェブロン | 4 px |
| ページ送りシェブロン | 5 px |
| アプリアイコンの線（SVG 48 viewBox の stroke 3 を 96 px 表示） | 6 px |
| Wi-Fi アイコン | 4 px（40 × 30 の SVG 内） |
| バッテリーアイコン | 3 px（56 × 28 の SVG 内） |

### 1.6 グリッドと余白

- 基本単位 **8 px**。左右マージン **64 px**、コンテンツ幅 **944 px**（x = 64 … 1008）。
- アプリ列だけは内側に寄せる: 円の中心 x = 224 / 432 / 640 / 848（間隔 208、円の間隔 48）。
- セクション見出しの四角は 16 × 16、見出しベースラインの 24 px 上。
- 文字のベースラインは原則 8 の倍数（表の値）。

| 文字数 | family / size | baseline | CSS top |

- Latin 名: 2 語以上なら各語の頭文字 2 文字（`Hacker News` → `HN`、`NHK NEWS` → `N`）。

- 大文字化する。空白・記号は使わない。

名前の省略:

- 描画幅が **256 px** を超える場合、末尾を `…`（U+2026）にして 256 px に収める。
  折り返しは禁止。文字幅は同じフォント・サイズ・字間で測る。
- 例: `はてなブックマーク` は `はてなブック…` になる。

## 7. 動的データのルール

### 7.1 お気に入り

- 1 ページ **最大 6 件**（3 列 × 2 行）。ページ数 = `ceil(n / 6)`。
- 0 件: `home-empty` の空状態 + 追加行。フッターは `0 件`。
- 1–3 件: 第 1 行にタイル、第 2 行に追加行。フッターは `n 件`。
- 4–6 件: 2 行をタイルで埋める。追加行は出さない。フッターは `n 件`。
- 7 件以上: 6 件ずつページ送り。フッターは §2.8 のページ送り。追加行は出さない。
- 2 ページ目がある場合、最終ページは 1–6 件。空きマスは白のまま。
- 番号は通し番号（2 ページ目は 07…）。3 桁になる場合は 3 桁を許容する
  （番号 box 48 px に右揃え。24 px × 3 桁 = 約 42 px で収まる）。

### 7.2 時計・日付・マストヘッド

- 時刻: 24 時間制、`HH:MM`、ゼロ埋め。フォントは SerifB 264 / ls -8。
- 日付: `M月D日 曜日`（ゼロ埋めなし）。曜日は gray-1。
- マストヘッド: `NO. %03d / 365`（閏年 366）。通算日。
- 更新: 時計矩形のみ毎分。日付・NO. は日付変更時。

### 7.3 テキストの揃えと省略（C 実装）

- 左揃え: 文字列の描画開始 x = 表の x。
- 中央揃え: 開始 x = 表の x + (表の w - 文字列幅) / 2。
- 右揃え: 開始 x = 表の x + 表の w - 文字列幅。
- 文字列幅は同じ TTF・サイズ・字間で測る。字間は「文字間」であり、最後の文字の
  後ろには付けない（HTML の letter-spacing と同じ見え方にしたい場合は末尾分を
  差し引く）。
- お気に入り名だけは、256 px を超えたら 1 文字ずつ削って `…` を足し、256 px 以下に
  なる最大の文字列を描く。省略記号は U+2026。ベースラインは変えない。
- 1 行のみ。クリップ矩形はタイルの name box（x+16, y+134, 256, 44）。
- ステータスバーの SSID は 796 px、設定の SSID は 640 px を超えたら同じ規則で省略する。

### 7.4 設定の状態

- Wi-Fi ON: 黒トグル + 白ノブ右 + `接続中`。OFF: 白トグル + 黒ノブ左 + `オフ`。
  OFF の画像は `screens/settings-wifi-off.png`。レイアウトは ON と同一。
- フロントライト: 0…16。数値 `level / 16`。バーは level 個塗り。
- 新聞: 最終更新の日時を `M月D日 HH:MM` で表示。更新後は現在時刻。
- バージョン: `Kindle Home 1.0 (PW4)` 固定（ビルドで差し替え可）。

- アイコン PNG は表示サイズで作り、C 側で再サンプリングしない。
- 出力 PNG は 1072 × 1448、mode L、16 階調（0, 17, …, 255）、300 dpi。
