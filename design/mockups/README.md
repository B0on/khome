# Kindle Paperwhite 4 ホーム画面モック

実装前の方向性検討用の静止画モック。出力は 1072 × 1448、8-bit グレースケール、16 階調
（E-ink の見え方に寄せるため、レンダリング後に量子化している）。3 案とも
「ステータスバー / 時計・日付 / アプリ 4 つ / ブラウザのお気に入り 3 件」を載せている。

共通ルール: 純白 + 純黒 + グレー 2 段（#000 / #6b6b6b / 反転用の #b0b0b0）。グラデーション・
影・1px 線は使わず、罫線は 3px 以上。最小文字は 28px、アイコンラベルは 32–44px。
フォントは Noto Sans JP / Noto Serif JP（`fonts/`）を同梱し、Chrome から読み込んでいる。

## A — Stack（iOS 風）

黒塗りのスクワークルに白抜きの線画グリフを載せ、上部に大きな時計ウィジェットを置いた
スマホのホーム画面。白黒だけで iOS のウィジェット / 4 列グリッド / ページドット /
ホームバーを翻訳し、角丸と余白で柔らかさを出している。お気に入りは枠線だけのタイルにして
アプリ（塗り）と役割を区別。4 列グリッドは空きマスを残してあり、増えても行が増えるだけ。

## B — Index（エディトリアル / 新聞風）

新聞紙面の組み方をそのまま画面にした案。セリフ体の巨大な時刻、3px の罫線、字間の広い
小見出しでリズムを作る。アプリは円形の線画アイコン、お気に入りは番号とイニシャルの
索引リストとして並べ、アイコンより文字組みを主役にした。行が下に伸びるだけなので
項目が増えても崩れず、余白は紙面の息抜きとして残している。

## C — Frame（ブルータリスト / Metro）

Windows Phone の Metro を白黒に振り切った案。10px の外枠と 4–5px の太線、黒塗りタイルの
コントラストだけで構成する。時計とお気に入りは黒地に白の大きな文字、アプリは白地に
太い枠とグリフ、という反転でリズムを作った。塗りと太線だけなので E-ink でも滲まず、
タイルは 2 列 / 3 列のまま増やせる。

## 生成

```sh
bash design/mockups/render.sh
```

`src/home-{a,b,c}.html` をヘッドレス Chrome（1072 × 1448、device scale 1）で撮影し、
Pillow で L モードに変換して 16 階調（0, 17, …, 255）に量子化して `home-{a,b,c}.png` を
上書きする（300dpi の pHYs 付き）。Chrome は `CHROME=/path/to/chrome` で差し替え可能。
Pillow はリポジトリの `.venv` を優先して使う（`PYTHON=` でも指定可）。
